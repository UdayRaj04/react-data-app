# 📊 PrimeReact DataTable Practice

A simple React project built to practice and explore the powerful **PrimeReact DataTable** component.  
This project demonstrates sorting, pagination, filtering, row selection, and CRUD operations using mock data.

---

## 🚀 Features

✅ Display tabular data using **PrimeReact DataTable**  
✅ Client-side **sorting**, **pagination**, and **filtering**  
✅ **Row selection** and **multi-selection** support  
✅ **Responsive** layout for mobile and desktop  
✅ Clean UI with **PrimeFlex** and **PrimeIcons**

---

## 🧩 Tech Stack

- ⚛️ **React 18+**
- 💠 **PrimeReact**
- 🎨 **PrimeFlex**
- 🔤 **PrimeIcons**
- 🧰 **Vite** (for fast dev build)
